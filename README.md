<p align="center"><strong>Installers for OpenBark, the free, open-source AI scribe for veterinary medicine.</strong></p>

Download the latest version from the [Releases page](https://github.com/ANI-ML/openbark-releases/releases/latest) or from [openbark.io](https://www.openbark.io). Each release includes a `SHA256SUMS` file so you can check your download.

OpenBark is pre-alpha. The installers are not code-signed yet, so Windows and macOS show a warning the first time you open them.
